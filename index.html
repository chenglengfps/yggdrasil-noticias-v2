📚 Catálogo de fontes

O catálogo que o robô usa é data/fontes.json. O botão abaixo salva as alterações neste navegador. Para o robô 24/7 enxergar uma fonte nova, use Baixar catálogo e envie o arquivo atualizado para o GitHub, substituindo data/fontes.json.

🤖 Como a automação funciona

A cada 2 horas, o GitHub Actions executa o robô, lê data/fontes.json, procura notícias novas, usa Gemini quando configurado e publica no Telegram. O site é apenas o painel; ele não precisa ficar aberto para o robô funcionar.
